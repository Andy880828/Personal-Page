# 設計規範：深海 × 數據

整站是一次下潛：從暮色海面（0 m）一路到 4,000 m 的海床。每一段的顏色、光線與 3D 元素都由「深度」決定。

## 深度對映

| 段落       | 路由       | 深度          | 海洋分層 | 3D 主角                                  |
| ---------- | ---------- | ------------- | -------- | ---------------------------------------- |
| Hero       | `/`        | 0–10 m        | 海面     | 暮色天空、可互動的水面（漣漪）、夕陽光帶 |
| About      | `/about`   | 10–100 m      | 透光帶   | 水下光束、海雪、魚群                     |
| Skills     | —          | 100–200 m     | 透光帶   | 五顆技能氣泡（點擊切換分頁）             |
| Projects   | `/project` | 200–1,000 m   | 中層帶   | 資料探測器、水母                         |
| Experience | —          | 1,000–3,800 m | 深層帶   | 生物發光浮游生物 + bloom                 |
| Contact    | —          | 3,800–4,000 m | 海床     | 海床地形、熱泉與上升粒子                 |

實作：`src/lib/sections.ts`（段落與深度）、`src/lib/scroll.ts`（捲動 → 連續位置 pos）、`src/scene/path.ts`（pos → 相機高度、水色、霧、光量）。

規則：強調色一次只用一個主角；漸層只出現在 3D 與背景，不用在文字上。

## 字體

- **Noto Sans TC**（可變字重 300–900，子集化）：全站中文與內文。標題用 900，內文 400。
- **JetBrains Mono**（400–700，只含拉丁字母與符號）：深度、年份、標籤、終端機封面等「數據」。
- 兩個 woff2 合計 < 300 KB；改文案後跑 `npm run fonts`，`tests/unit/fonts.test.ts` 會擋漏字。

## 動效

| 名稱            | 曲線                             | 時長      | 用在                           |
| --------------- | -------------------------------- | --------- | ------------------------------ |
| tide            | `cubic-bezier(0.22, 1, 0.36, 1)` | 0.5–1.3 s | 標題浮出、卡片傾斜回彈         |
| swell           | `cubic-bezier(0.65, 0, 0.35, 1)` | 1.6 s     | 捲到某段                       |
| GSAP `expo.out` | —                                | 1.1–1.2 s | 段落內容進場（stagger 0.08 s） |

- 首屏標題用純 CSS 逐字浮出（不等 JS）；其餘動畫在首屏後載入 GSAP 才啟用，已在畫面內的元素不補動畫，避免閃爍。
- 「減少動態」：系統設定或導覽列的按鈕。關掉 Lenis、所有 CSS／GSAP 動畫，3D 改成只在捲動時重繪一幀。
- 測試模式 `?test=1`：固定亂數與時間、關閉所有動畫，給視覺回歸用。

## GPU 分級（`src/lib/gpu.ts`）

| 等級 | 條件                              | 內容                                          |
| ---- | --------------------------------- | --------------------------------------------- |
| 0    | 沒有 WebGL2、省流量模式、場景出錯 | 純 DOM + CSS 背景                             |
| 1    | 手機、弱 GPU、軟體算繪            | 無後製、魚 120 隻、海雪 800、DPR ≤ 1.5        |
| 2    | 一般桌機                          | 後製（bloom、vignette）、魚 260 隻、海雪 2000 |
| 3    | 高階 GPU                          | 魚 360 隻、海雪 2600、DPR 2                   |
